# برنامه‌ی تست و معیار انتشار

## واحد
- محاسبه‌ی اندازه‌ی موقعیت و ریسک
- سقف زیان روزانه/هفتگی و drawdown
- precision و محدودیت نماد
- تشخیص داده‌ی کهنه/ناقص
- محاسبه‌ی کارمزد و slippage
- idempotency و جلوگیری از سفارش تکراری

## یکپارچگی
- adapter با پاسخ‌های موفق، رد سفارش، timeout و partial fill
- reconciliation پس از restart
- قطع WebSocket و بازیابی
- هم‌زمانی دو سیگنال روی یک نماد
- فعال‌شدن kill switch در حین اجرای چرخه

## سناریوهای الزامی ایمنی
- config پیش‌فرض هیچ‌گاه سفارش live نسازد
- live flag خاموش باشد ولی مدل BUY بدهد => رد
- سقف زیان فعال شود => سفارش جدید رد
- داده کهنه باشد => سفارش جدید رد
- وضعیت سفارش timeout باشد => قبل از retry استعلام
- API دارای withdrawal باشد => اتصال live رد شود
- secret در log دیده نشود

## انتشار
- lint/type-check/test سبز
- تست بک‌تست بدون look-ahead
- گزارش paper trading مستند
- اسکن secrets و وابستگی‌ها
- هیچ خطای بحرانی باز نمانده باشد
